# Reference parity — iteration 1

The two shallow clones under ignored `_reference/` are comparison material, not dependencies or native Unity evidence. `darkorbit-emulators` contains several older server implementations; `Darkorbit-client` is a Flash wrapper and packet inspection tool, not a gameplay server. Their packet identifiers and framing must not be copied into the provisional Unity world protocol without a captured fixture. The relevant local contract is [world-protocol.md](world-protocol.md).
