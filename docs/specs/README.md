The `SPEC-06` prelogin parser now has loopback coverage for truncated, invalid UTF-8, and trailing-byte version and login payloads. An architecture invariant pins the handshake, decoder, resolver, and malformed-error order.

The `SPEC-06` prelogin handshake now has loopback coverage for retrying a rejected version request, revoking earlier acceptance with a later mismatch, and rejecting a login whose own version disagrees or whose instance ID is empty or overlong. These failures return `UnsupportedVersion`, end the handler, and suppress identity resolution. An architecture invariant pins both version gates and the instance-ID bound ahead of resolver admission.

The `SPEC-06` configured frame limit now has wire-boundary coverage at both allowed option extremes (64 and 1,048,576 body bytes). Exact-size frames round-trip without consuming the following frame; one extra byte fails before outbound writes or inbound body reads. An architecture invariant requires the world session handler to use the configured limit in both codec directions.

The `SPEC-06` packet frame contract now pins the default 65,536-byte body limit at both boundaries: a 65,534-byte payload round-trips without consuming the next frame, while one extra byte is rejected before writing or reading a body. Two feature cases and an architecture invariant guard the header-inclusive accounting and validation order.

The `SPEC-06` travel projection now defines midpoint-to-even rounding for fractional recorded origins, including negative halves. A same-map retarget uses the resulting integer position for both duration and the next travel origin. Four feature cases and an architecture invariant pin that boundary.

The `SPEC-06` movement interpolation contract now pins nonpositive speed across past, present and future samples, plus retargeting from a stationary same-map trip versus a foreign-map trip. A feature fixture checks the exact origins and durations; an architecture invariant requires `Begin` and `Travel` to share the map-scoped interpolation rule.

The `SPEC-06` ship-stat calculator resolves catalog overrides per assigned item and requested stat field. Zero and 1,000,000 are accepted; the first matching listing controls fallback when its requested field is missing or invalid. Feature tests pin field isolation and duplicate-listing order, while an architecture test keeps bounded lookup in the pure World slice.

The `SPEC-06` entry burst defines safe-zone distance over widened 128-bit coordinate differences and squared values. Four extreme-coordinate cases cover subtraction wraparound, an inclusive maximum-radius point, and a squared sum beyond the radius. An architecture test pins widening before subtraction in the shared entry emitter.

The `SPEC-06` movement contract widens target-minus-origin coordinate differences before calculating distance, saturates positive-speed durations at `Int32.MaxValue` milliseconds, and bases radiation warnings on requested target bounds. Feature tests cover opposite signed-coordinate extremes from both saved and same-map-travel origins, plus finite high-speed, saturated low-speed and zero-speed outcomes. An architecture test pins the widening and saturation order in the World slice.

The world listener shutdown contract in `SPEC-06` has live socket coverage for fixed and single-port-range binding: an idle pending accept completes and the port can be rebound after `StopAsync`. Port-range parsing has culture-independent ASCII syntax and publishes output bounds only after full validation. Dynamic binding ignores the incoming configured port in both unrestricted and ranged modes, then publishes the selected socket port. Option and architecture tests enforce these rules.

The `SPEC-06` frame codec now has cancellation coverage at all three read stages (before a header byte, during the remaining header, and during the body) plus a pre-canceled write. These tests distinguish cancellation from EOF and truncated packets, and an architecture test pins token forwarding to each stream operation.

The `SPEC-06` frame codec also owns its asynchronous I/O buffers: a write snapshots the caller's payload before awaiting the stream, and a read's payload remains stable after later frames are read. Feature tests cover a blocked write and consecutive reads; an architecture test guards allocation and copy order.

The `SPEC-06` authenticated TCP handler now maps invalid UTF-8, truncated strings and trailing bytes in authorized admin-command payloads to a single `Malformed` wire error and closes without dispatching. Loopback tests exercise the exact packet response and unauthorized precedence, and an architecture test guards the decoder exception boundary.

The `SPEC-06` world HTTP JSON gate now compares the complete media type, allowing case differences and semicolon parameters while returning 415 for JSON prefix lookalikes. Feature tests cover rejected mutation requests before authentication or body reads and accepted moves with common content types; an architecture test keeps all eight write routes on the shared gate.

The `SPEC-06` TCP pilot resolver now has tests for blank and 128/129-character session tokens, expired-session precedence, nonpositive user IDs, and account lookup suppression. Successful pilot projection is checked field by field, and an architecture test pins the ordered validation boundary within the World slice.
